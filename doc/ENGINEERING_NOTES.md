# 工程笔记：这套 IAP 为什么这样设计

这一页不是开发日志的逐日流水账，也不是再抄一遍芯片手册。我把工程中几个最值得解释的地方单独记下来。数字和测试状态以 [固件身份](../Firmware/IDENTITY.json) 与 [验证文档](VALIDATION.md) 为准。

## 1. Bootloader 的容量问题

这颗 STM32F103C8T6 按正常规格只有 64KB Flash、20KB SRAM。我把内部 Flash 留给 Boot **16KB**、App **48KB**，也不依赖“某些板子可能有更大实际容量”来绕过限制。

结果就是：Boot 里放一个功能，可能就要为它的每一百字节付出代价。当前正式 Target 的 ROM 是 **16,372B**，只比上限少 12B。这里主要想体现的是**最终链接后的真实占用**，不是靠单个函数编译大小估算。

因此仓库保留 MDK 工程、散装文件、构建审查脚本及固件哈希。后面如果要修改 Boot，首先要重新构建、看 MAP/实际 ROM，再决定能不能烧进去。不能把“已经能编译”当成“还有功能余量”。

## 2. 为什么一定要外部 Flash

升级不能让正在运行的 App 在没有有效备份时直接覆盖自己。

当前 W25Q64 的设计把 **Download、Backup、Metadata、升级日志** 分开；App 业务历史另外独占一块区域。Download 通过完整接收、格式检查、CRC 和读回校验才允许成为可信候选；旧 App 也要有可信 Backup，安装过程才有回退基础。

元数据不是简单的一位“升级完成”标志。状态先落盘、再进入可能破坏数据的动作，目的是让启动时知道此前走到哪一步，不能把半成品当成有效固件。具体状态转换和允许擦写的前置条件，请看 [设计文档](DESIGN_SPEC.md)。

> 这说明的是**设计和离线测试覆盖**，不说明所有真实断电点都被测过。真实 Flash 供电中断、页擦写与 Metadata 竞争场景还需要真机故障注入。

## 3. 为什么新版本启动了也不直接确认成功

升级文件通过校验，只能说明镜像比较像一份完整镜像；跳转到新 App，也不等于业务任务在正常跑。

因此我保留了 Trial 流程：App 启动以后，业务进展、ADC/OLED 初始化、串口 Ready、最短运行时间等条件满足，才发起健康确认。Boot 负责检查和提交最终状态。试运行失败最多进行三次尝试，再依据可信备份决定回滚；没有可信路径就留在 Boot，而不是盲目跳转。

IWDG 也是同一个思路：不能只为了“有喂狗”而无条件喂狗。实际停机/回滚能力仍以对应硬件证据为准。

## 4. UART 和升级命令为什么要明确分层

这个项目同一串口既承担 `@APP:` / `@IAP:` 的文本命令，也要传输 YModem 二进制包。串口 IDLE 或 DMA 缓冲到达的位置，不应该被想当然地当成完整协议帧结束。

所以要区分接收缓冲、文本命令解析、YModem 收包与升级状态处理。维护串口路径时，我更看重**丢包、边界字节、超时、非法命令**怎么被明确处理，而不只是短字符串能回显。

本工程的 YModem V1 是标准单文件发送，不支持断点续传。接收中断后不能默认断点继续，应重新走实际规定的升级流程。

## 5. 让 App 做一点实际业务，问题才会显露

Application 用 FreeRTOS 的串口通信、升级控制和业务三个任务。业务任务负责片内温度采样、OLED 显示和外部 Flash 历史数据，历史记录带有恢复扫描与循环覆盖机制。

加入持续写入以后，项目才不只是单次串口升级：业务存储区域必须和 IAP 保持隔离，扫描不能无限阻塞任务，升级交接也不能和存储操作互相打架。

串口记录已观察到复位后历史序号继续，但目前温度读数出现 **约 -38～-39℃** 的异常。如果在室温下测试，这个结果不合理；优先需要核查 ADC 校准、公式和读数含义，不能直接把它写成准确温度测量。

## 6. 现在我怎么区分“做了”和“通过了”

- **实现层：** 可查阅 Boot/App/Shared 的源码和 Keil 工程。
- **构建层：** 已有正式 Target 的 AC5 完整构建和大小记录。
- **主机测试：** 14 组离线回归有对应记录，用于检查协议、状态机和边界条件。
- **板端观察：** 有用户提供的升级后 V2 正常运行、历史记录恢复等串口日志，但不是所有项目都做了独立读回和实物复核。
- **仍开放：** 写入时掉电、可信 V1 回滚、满环覆盖、部分 PB12/看门狗最坏情况，以及温度精度等。

我希望这个项目对面试官有价值的地方，不是看起来“功能非常多”，而是**每一步都能指出代码、说明为什么要这样做，也能坦然说清楚哪些证据还没有**。
